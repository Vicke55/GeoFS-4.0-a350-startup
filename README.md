# GeoFS A350 Startup

A custom Airbus A350 startup panel for **GeoFS 4.0**.

This project adds an interactive A350-inspired startup interface to GeoFS, allowing you to control the aircraft through a visual startup panel instead of using only the standard GeoFS controls.

## Features

* Airbus A350-inspired startup interface
* Interactive cockpit controls
* Clickable buttons and switches
* Startup sequence
* Visual system states
* Cockpit click sounds
* Startup progress tracking
* Reset functionality
* Designed specifically for the Airbus A350 in GeoFS 4.0

## Requirements

* **GeoFS 4.0**
* **Tampermonkey**
* A modern web browser

## Installation

### 1. Install Tampermonkey

Install the Tampermonkey browser extension for your browser.

Official website:

https://www.tampermonkey.net/

### 2. Install the userscript

1. Open `a350-startup.user.js` in this repository.
2. Click **Raw** on GitHub.
3. Tampermonkey should open the installation page.
4. Click **Install**.

If the installation page does not appear, copy the contents of the `.user.js` file and paste it into a new Tampermonkey userscript.

## Usage

1. Open **GeoFS 4.0**.
2. Select the **Airbus A350**.
3. Make sure the A350 Startup userscript is enabled in Tampermonkey.
4. Open **A350 STARTUP** in the GeoFS interface.
5. Use the interactive panel to perform the startup.

Your startup progress is preserved when the panel is closed and reopened. Use the reset function when you want to start the procedure again.

## Compatibility

This addon is made specifically for **GeoFS 4.0** and the **Airbus A350**.

Compatibility with other GeoFS versions or aircraft is not guaranteed.
